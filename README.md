# maps

Всё содержимое (карты, данные, инструменты `_tools/`, инструкция `_tools/README.md`) живёт в ветке `gh-pages`.
В `main` только workflow по расписанию (`update-statika`), потому что GitHub запускает cron только из ветки по умолчанию.

Секреты репозитория: `GOOGLE_SA_JSON` (ключ сервисного аккаунта Google static-sov-writer@static-sov.iam.gserviceaccount.com).
